# Bud-E

A 21+ night-garden companion for a cannabis session. Log the night, keep a personal shelf and stash jars, run a wait timer, and sign in.

Journal and stash stay on this phone. They are not saved to the account. This is not medical advice, a shop, or a reason to drive.

## Run

```bash
npm install
npm run dev
```

Confirm you are 21 or older on the first screen, then create an account or sign in.
